# Icon

Inline SVG icons sourced from [Central Icons](https://centralicons.com). Each
icon is a self-contained component with **no runtime dependency** on
`@central-icons-react` - the SVG path data is inlined at build time by the
generator, so nothing icon-related ships in the dependency graph at runtime.

## Usage

```tsx
import { IconArrowUpRight, IconSize } from '@repo/design-system-ui/icon'

// Size defaults to IconSize.Medium (20px)
<IconArrowUpRight />
<IconArrowUpRight size={IconSize.Small} />   // 16px
<IconArrowUpRight size={IconSize.Large} />   // 24px

// Color comes from currentColor, so it inherits the text color:
<IconArrowUpRight className="text-text-secondary" />
```

## Sizes

`size` is a named token. The values match the icon sizes used across the brand
frames (16 / 20 / 24px).

## Accessibility

Icons are decorative by default (`aria-hidden`), so screen readers skip them -
ideal when the icon sits next to a text label. When an icon stands alone and
conveys meaning, pass `title` to give it an accessible name:

```tsx
<IconArrowUpRight title="Opens in a new tab" />
```

## Adding icons

The `@central-icons-react` source packages are only needed at generation time.
The script auto-installs them to a temp directory and removes them afterward.
Set `CENTRAL_LICENSE_KEY` in `.env.local` to use your Central Icons license.

```bash
# From packages/ui-design-system
pnpm icons:add IconName1 IconName2

# Filled variant (outlined + filled artwork toggled via the `fill` prop)
pnpm icons:add --filled IconHeart

# Heavier stroke-2 variant (component name gets a "Heavy" suffix)
pnpm icons:add --heavy IconShieldCheck

# Preview without writing files
pnpm icons:add --dry-run IconName
```

Icon names must match Central Icons names exactly. The generator regenerates
`generated.ts` and writes a component to `./icons/<Name>.gen.tsx`.

## Brand / platform icons

A few platform logos in the brand frames aren't part of Central Icons
(`IconWindows`, `IconAndroid`). These are hand-authored from the open-source
Iconify sets (`mdi`, `material-symbols`; both Apache-2.0) as plain `.tsx`
components that share the same props and `currentColor` behaviour. They live
alongside the generated icons and the generator leaves them untouched.

## File structure

```
icon/
├── index.ts          # Public barrel (hand-maintained): re-exports generated + brand icons + types
├── generated.ts      # Central Icons re-exports (auto-generated by the generator)
├── types.ts          # IconSize, IconFill, IconProps
├── stories.tsx       # Storybook stories
├── docs.mdx          # This page
└── icons/
    ├── <Name>.gen.tsx  # Generated Central Icons - do not edit
    └── <Name>.tsx      # Hand-authored brand/platform logos
```

Generated files carry a `@generated` annotation and a `.gen.tsx` extension;
Biome skips them and they should never be edited by hand.
