# Colors

## Token types

### Primitives

Raw values you will rarely use directly. Prefer the semantic tokens below.

- **Opacity (black)** - `--color-opacity-1` through `--color-opacity-80`. The working neutral ramp: text, borders, and subtle fills on light surfaces.
- **Opacity (white)** - `--color-opacity-inverted-20/40/75/80`. Text and fills on dark surfaces.
- **Tonal (opaque)** - `--color-tonal-10/20/30/40` (the light surfaces) and `--color-tonal-100` (opaque black). The mid-range is intentionally absent; mid greys come from the black-alpha ramp.

### Semantic tokens

Purpose-driven tokens that reference the primitives. These are what you should reach for.

```css
/* Text */
--color-text-primary       /* opacity 80% - headings, primary body */
--color-text-secondary     /* opacity 60% */
--color-text-tertiary      /* opacity 40% - body, meta, inactive nav */

/* Surfaces */
--color-surface-primary    /* #ffffff */
--color-surface-secondary  /* #fafaf8 - sections, footer */
--color-surface-inverse    /* black 80% - dark buttons/cards */

/* Borders */
--color-border-default     /* opacity 10% */
--color-border-subtle      /* opacity 8% */
```

## Usage

### With Tailwind

```tsx
<div className="bg-surface-primary text-text-primary border border-border-default">
  Content
</div>

<p className="text-text-tertiary">Last updated on May 1, 2026</p>

{/* Dark button: inverse surface + inverse text */}
<button className="bg-surface-inverse text-text-inverse">Get access</button>
```

### With CSS variables

```css
.card {
  background: var(--color-surface-primary);
  color: var(--color-text-primary);
  border: 1px solid var(--color-border-default);
  box-shadow: 0 1px 2px var(--color-shadow-default);
}
```

## Choosing the right token

### Text

    <tr><td><code>strong</code></td><td>The rare opaque-black headings and logo art (#000000)</td></tr>
    <tr><td><code>inverse</code></td><td>Labels on dark surfaces (#ffffff)</td></tr>

  </tbody>
</table>

Icon tokens (`icon-primary`, `icon-secondary`, `icon-inverse`) mirror the text hierarchy so an icon always matches its label.

### Shadow

`--color-shadow-default` (black 20%) is the single elevation color observed in the frames (the app-icon drop shadow). Use it as the color inside a `box-shadow`.
