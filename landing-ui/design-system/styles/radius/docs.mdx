# Radius

Corner-radius scale measured from the May 2026 brand frames. Tailwind v4's default radius scale already matches the brand, so `src/styles/radius/radius.css` only adds the one tier Tailwind lacks - `--radius-4xl` (32px).

```tsx
{/* Tailwind utility */}
<div className="rounded-3xl bg-surface-primary border border-border-subtle p-8" />

{/* CSS variable directly */}
<div style={{ borderRadius: 'var(--radius-3xl)' }} />
```

`Surface` exposes the surface radii through its `radius` prop: `sm` (16px), `md` (24px, default), `lg` (32px).

## Don't use arbitrary values

Reach for a token, not `rounded-[22px]`. The scale is intentionally narrow so adjacent surfaces compose without visual noise. If no token fits, raise the scale rather than the callsite.
